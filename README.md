# Vehicle Management Api

API REST para gerenciamento de carros, motoristas e utilização de veículos da empresa.

O projeto foi desenvolvido como parte do desafio técnico para a posição de Backend Node.js Pleno.

## Tecnologias

- Node.js
- Express
- Jest
- Supertest
- JavaScript
- Persistência em memória

## Requisitos

- Node.js 18 ou superior
- npm
